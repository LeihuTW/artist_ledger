# 繪師委託帳本 下載

給繪師和委託者用的記帳本：記錄委託、收付款、交稿日、修改過程和完稿。同一個程式裡有兩本帳，左上角切換：

- **繪師帳**：記錄接到的委託、收款、死線，可以做公開排單。
- **委託者帳**：記錄你委託繪師的進度、付款、交稿日，並為每位繪師建一張資料卡（排單頁、價目表、收款方式）。

目前版本：**1.4.2**｜製作人 肯茲｜問題回報：leihustore@gmail.com

## 主要功能
- 委託總覽看板：依進度階段排列，一眼看出進行中、即將到期、待收／待付款。
- 委託人／繪師資料卡：標籤、社群與聯繫方式、角色設定圖與參考資料、委託歷史、聯繫紀錄都在同一張卡。
- 標籤與搜尋：名冊上點標籤就篩選；搜尋會找名字、標籤、聯繫方式、備註和委託項目。
- 新增委託可選「快速記錄」（只填繪師、項目、金額、訂金）或「完整」輸入。
- 修改過程圖版本與並排比較、完稿圖庫、交稿行事曆、到期提醒。
- 自動備份（電腦版）：改完一分鐘後、開機時、每 6 小時自動備份到你指定的資料夾（例如 Google 雲端硬碟電腦版、外接硬碟）。
- 電腦與手機同步：存在你自己的 Google 試算表。
- 匯出 Excel／CSV、Google 表格同步、隱私模式（直播截圖時打碼）、深色模式、畫面大小 100%～150%。
- **我的資料卡**：做一張可分享的繪師／委託者資料卡圖片，另附「名片代碼」，對方貼到名冊就能直接建立資料卡。
- **共享個案頁**：一單產生一個網址，對方用瀏覽器就能看進度、交稿日、你寫的備註並留言，留言會自動進到聯繫紀錄。
- **雙方同步**：對方也用繪師委託帳本時，貼上共享網址，這一單的進度、交稿日和對話會雙向同步。

## 電腦版（Windows 10／11）

### 安裝版
1. 下載 `ArtistLedger-Setup-1.4.2.exe` 並執行。
2. Windows 若跳出「Windows 已保護您的電腦」，按「其他資訊 › 仍要執行」（程式沒有付費的程式碼簽章，所以會出現這個提示）。
3. 不需要系統管理員權限。資料存在「文件\ArtistLedger」，解除安裝時不會刪除。
4. 第一次開啟會有設定精靈，記得到「設定與備份」加一個備份位置。

### 免安裝版
1. 下載 `ArtistLedger-Portable-1.4.2.exe` 並執行，選一個資料夾（例如 `D:\ArtistLedger-Portable`），程式會解壓縮到那裡。
2. 之後執行資料夾裡的 `ArtistLedger.exe`。資料存在同資料夾的 `data`，整個資料夾可以帶著走。
3. 請不要刪掉資料夾裡的 `portable.txt`，也不要放在「Program Files」。
4. 免安裝版沒有開始功能表捷徑，Windows 可能不會跳提醒，到「設定與備份」按「建立桌面與開始功能表捷徑」即可。

### 從舊版升級
直接安裝新版即可，資料不會消失。若有用 Google 表格同步，請到「Google 表格同步」頁重新複製同步腳本，貼到 Apps Script 全部取代，再到「部署 › 管理部署作業 › 編輯 › 版本：新版本」重新部署一次。1.4.0 的共享個案頁需要這個新版腳本。

## 網頁版本

手機版是可以「加到主畫面」的網頁 App，畫面和功能與電腦版幾乎相同。

1. 用手機瀏覽器打開 **[https://leihutw.github.io/artist_ledger/](https://leihutw.github.io/artist_ledger/)**（安卓用 Chrome、iPhone 用 Safari）。
2. 安卓：右上角選單 › 「加到主畫面」或「安裝應用程式」。iPhone：分享按鈕 › 「加入主畫面」。
3. 從桌面圖示打開就是全螢幕，跟一般 App 一樣。開過一次之後，沒有網路也能打開和記帳。

### 資料存在哪裡
手機版的資料存在那支手機的瀏覽器裡，不會傳到這個網站。清除瀏覽器資料會一併刪掉，所以建議一定要設定同步，或定期在「設定與備份」匯出備份檔。

### 和電腦同步（掃 QR code）
1. 電腦版先完成「Google 表格同步」的設定（頁面上有步驟）。
2. 在電腦版「Google 表格同步 › 電腦與手機同步」按「顯示 QR code 與連線代碼」。
3. 用手機相機掃 QR code，點出現的網址，手機版打開後按「連線」就完成了。
   - iPhone 已經把手機版加到主畫面的話：請打開主畫面的 App，到「Google 表格同步」按「掃描 QR code 連線」來掃，資料才會存在那個 App 裡。
   - 掃不到時的備用方案：在電腦按「複製」連線代碼（`AL1-` 開頭），貼到手機版同一頁的輸入框，按「連線」。
4. 之後兩邊會自動同步：修改後約 15 秒上傳，打開 App 時拉取最新資料。繪師帳和委託者帳都會同步。

**這組代碼等於你的帳本鑰匙，請不要用 LINE 或 Email 傳送，也不要截圖。** QR code 和代碼 2 分鐘後會自動隱藏，隱私模式中不顯示。資料存在你自己的 Google 試算表，不會經過其他伺服器。圖片不會同步，只同步文字資料。

### 手機掉了怎麼辦
1. 在電腦版「Google 表格同步」頁，同步密碼旁按「重新產生」。
2. 按「複製同步腳本」，回到 Apps Script 全部刪掉後貼上。
3. 在 Apps Script 按「部署 › 管理部署作業」，按鉛筆圖示「編輯」，版本選「新版本」，按「部署」（網址不會變）。
4. 其他還要用的裝置，重新掃 QR code 或輸入新的連線代碼。

完成後，掉的那支手機就不能再讀取或修改你的帳本。代碼不小心傳出去或被截圖時，也照這個步驟換掉。

## 分享給對方

### 我的資料卡
1. 左側選單（手機在「更多」）點「我的資料卡」，按「開始填寫」。
2. 填好後按「下載圖片」（手機是「分享／下載圖片」，可以直接傳到 LINE、Discord），或按「複製名片代碼」。
3. 對方如果也用繪師委託帳本，到名冊按「貼上名片代碼」就會建立一張資料卡。

資料卡會給別人看，不要放完整帳號、地址或電話。

## 共享個案：讓對方看到這一單的進度，也能和你對話

### 這是什麼
你可以在某一筆委託按「開啟共享」，程式會給你一個網址，把它傳給對方就好。對方有兩種用法：

- **只看網頁**：對方用手機或電腦的瀏覽器打開網址，就能看進度、留言，不用安裝任何東西。
- **雙方同步**：對方也用繪師委託帳本的話，把網址貼進程式，這一單就會自動同步到他的帳本。

以下說的「你」是開啟共享的人，「對方」是收到網址的人。繪師和委託者都可以當開啟共享的那一方。

### 開始前要先做（只有你要做，做一次就好）
1. 在「Google 表格同步」頁完成設定，頁面上有步驟。
2. 換成 1.4.0 的同步腳本：
   1. 在「Google 表格同步」頁按「複製同步腳本」。
   2. 回到 Apps Script，把原本的內容全部刪掉，貼上剛剛複製的腳本。
   3. 按「部署 › 管理部署作業」，按鉛筆圖示，版本選「新版本」，再按「部署」。
3. 確認部署的「誰可以存取」是「所有人」。不是的話，對方會打不開網址。

對方什麼都不用設定。

### 你要怎麼分享
1. 打開要分享的那一筆委託。
2. 在右側（手機在下方）的「共享個案頁」按「開啟共享」。
3. 程式會自動同步，大約幾秒鐘。等不及可以按「立即同步」。
4. 按網址旁的「複製」，用 LINE、Discord 或私訊傳給對方。
5. 想讓對方知道的事，寫在「給對方看的備註」。例如：「草稿預計週五給你看」。
6. 想讓對方看到金額，才勾「顯示金額與已付款」。不勾的話，金額不會出現在網頁上。
7. 要傳訊息給對方，在下方的對話框打字，按「送出」，下次同步時就會送出。

### 對方只看網頁時
打開網址後，對方會看到：
- 委託名稱、編號，和你的名字
- 進度條、目前在哪個階段、交稿日
- 階段日期，例如草稿、線稿各自的日期，完成的會劃掉
- 你寫的「給對方看的備註」
- 金額和已付款（只有你勾選時才會出現）
- 你們的對話

對方可以在網頁最下面填名字、留言，按「送出留言」。要重新整理網頁，才會看到你的新訊息或更新的進度。

對方的留言，會在你下次同步時出現在這一單的對話裡，也會自動記到對方資料卡的「聯繫紀錄」。

### 對方也用繪師委託帳本時（雙方同步）
1. 對方打開繪師委託帳本，在「委託總覽」按「加入共享個案」。
2. 把你給的網址貼上（連同其他文字一起貼也沒關係），按「加入」。
3. 對方的帳本會自動建立這一單，並建立一張你的資料卡。

之後：
- 你改了進度或交稿日，對方帳本裡的這一單會自動跟著改。
- 兩邊都在這一單的對話框傳訊息，對方會收到你的，你也會收到對方的。
- 程式每 5 分鐘同步一次，打開程式時也會同步，也可以隨時按「立即同步」。電腦版收到新訊息時會跳通知。
- 對方不需要設定 Google 表格同步，也不需要自己的同步腳本。
- 對方自己記的付款紀錄、備註、標籤都只存在他自己的帳本，不會傳給你。
- 不想再同步時，對方可以按「停止追蹤」。這一單會留在他的帳本裡，只是不再更新。

### 兩種用法的差別

| | 只看網頁 | 雙方同步 |
|---|---|---|
| 對方需要安裝程式 | 不用 | 要 |
| 看進度、交稿日 | 打開網頁看 | 自動更新到對方的帳本 |
| 留言、傳訊息 | 在網頁最下面留言 | 在程式裡這一單的對話框 |
| 收到你的新訊息 | 要重新整理網頁 | 同步時自動收到，電腦版會跳通知 |

### 哪些內容會被看到
- **網址就像鑰匙**：拿到網址的人都能看、都能留言，請只傳給對方本人。
- **會看到**：委託名稱、編號、你的名字、進度、交稿日、階段日期、給對方看的備註、對話，以及你勾選時的金額和已付款。
- **不會看到**：委託人的真實姓名、聯繫方式、私人備註、收款帳戶、每一筆付款明細、圖片和原檔，還有你的其他委託。
- **停止分享**：按「停止共享」後程式會馬上同步，網址就打不開了。已經傳出去的訊息，對方那邊還是看得到。

### 常見問題
- **對方打開網址，看到「找不到這個個案」**：可能是還沒同步完成，按一次「立即同步」再請對方重新整理。也可能是你已經停止共享，或是腳本的「誰可以存取」不是「所有人」。
- **按「開啟共享」後出現「需要新版同步腳本」**：照「開始前要先做」的第 2 步，重新貼上腳本並部署新版本。
- **對方的留言沒有出現**：按「立即同步」。
- **「共享個案頁」裡沒有「開啟共享」按鈕**：表示還沒設定 Google 表格同步，照「開始前要先做」的第 1 步設定。
